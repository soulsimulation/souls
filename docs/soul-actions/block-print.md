# Block printing

Place `core/block-print-paper@1` on a work surface. Normal inspect offers sixteen choices: four cells (`bl/br/fl/fr`), disc or bar, red or blue. Each completed six-second native craft prints only that cell and uses one of four supplied ink charges. Existing navigation and body time remain authoritative; interrupting work preserves ink and composition. The default brush/stamp is a visual proxy, not borrowed tool custody.

Normal current `inspect.state.blockPrint` reports all four motifs/colors, remaining ink and last maker. Generic sign reading is not claimed. Work requires permission, a set-down sheet on its actual support, empty hands, native same-floor proximity and clear standing room. The same paper retains its composition through ordinary pickup/carry/putdown and persistence; put it on a work surface again to print. No freehand drawing, drying/ink chemistry or precision contact is simulated.

The exact-definition receipt helper binds the started target/support/transform and composition; only a matching completed receipt commits the same sheet and ink atomically. Interrupted, duplicate, missing-start and stale callbacks do nothing. Nearby offers/current detail have bounded nonzero cost; no new idle/background scan is added. Existing request-time held-item lookup is reused.
