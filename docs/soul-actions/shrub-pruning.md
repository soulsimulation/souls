# Selective soft-shoot pruning

`core/pruning-shrub@1` exposes six independent `prune-<side>-<height>` choices. Each completed four-second native
`operate` hand-work pose removes only that chosen shoot, retains a cutting in the shrub's own catch tray and records
the latest pruner. Any subset/order creates a persistent silhouette; there is no regrowth or fresh portable output.

The exact-definition helper rechecks access, empty hands, actual actor/body identity, unchanged shrub definition,
pose/state, native duration, reach and floor at completion. Interrupted, replaced, changed, missing or duplicate work
cannot commit a cut. Current inspect facts describe remaining shoots, retained count and latest branch/pruner.
State is ordinary entity state and survives snapshots/restarts. No new idle scan, physics or protected engine contract.

Native `craft` was rejected during early visual review because it defaults to a hammer. Existing prop-free `operate`
provides approximate hand work; no tool custody or fine grip/contact claim. The authored branches/foliage are coarse
geometry, not botanical growth or material-volume simulation. Additive named God hooks need serial integration.
