# Rainwater collection

`core/rainwater-collector@1` is a fixed4L source. Uncover/cover and collecting one1L batch use four completed seconds of existing native craft. Collection needs free hands, rain, an open inlet and room; interruptions or changed collector/weather/time context preserve prior water. No passive accumulation, scientific rate or purity claim.

Existing W5 `draw-water` transfers available stored litres into the same held compatible watering can. It remains the existing water action; source loss equals vessel gain. Current exact-def `rainwater` facts expose the collector's own amount/cover/history and authoritative rain requirements, not remote target state.

The [canonical direction](https://github.com/soulsimulation/souls/blob/647d04a5ce5621717c2fad78c153d082e3dffcb2/docs/design/soul-actions-direction.md) applies: basic coherence, existing mandatory proof and Claude-only integration. New named God hooks are additive; no engine, registry or generic reader contract changes.
