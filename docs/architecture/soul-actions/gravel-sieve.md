# Camp gravel sieving

`core/gravel-sieve@1` is one portable integral tray with three supplied mixed batches. Each batch represents one coarse and two fine units, so `3*mixed + coarse + fine = 9`. `object:<tray-id>:sieve` separates one mixed batch; `object:<tray-id>:remix` reverses exactly that. Both kind acts and all numeric stocks are declared data. Current `gravelSieve` inspection facts include full stocks, conserved total, completed count, maker and requirements. Agent discovery uses the actual catalog/find ID, followed by the exact act ID; no word rule or generic reader change.

Existing three-second native operate handwork owns time. A matching started/completed receipt binds source definition/state/parameters, current owner/access/pose/support and the actual Soul body/action. Completion rechecks material, floor, reach and authority. Failed, interrupted, stale, duplicate or unstarted work cannot change fractions. The shared engine-authored completion adapter preserves unrelated God Undo/redo.

Put the tray on a fixed work table and empty hands before work. Native pickup and ground putdown are storage/transport; work resumes after normal put-on-table. The SAME tray retains integral material and identity; fractions are not separate carryable objects. No particle simulation, geological accuracy, sieve mesh/contact precision, independent fraction custody or new motion/physics contract is claimed. Existing approximate tabletop handwork is sufficient; final release must not leave a borrowed tool or contradictory prop.

New named `gravelSieve` God hooks are independent additive seams. Claude integrates them serially alongside other action branches. Exact reviewed catalog/completion/discovery/conformance/startup dependencies remain explicit until integrated. Follow the [canonical direction](https://github.com/soulsimulation/souls/blob/647d04a5ce5621717c2fad78c153d082e3dffcb2/docs/design/soul-actions-direction.md); mandatory checks, privacy, T3 comparison and maintainer approval remain separate.
