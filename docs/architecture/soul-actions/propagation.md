# Garden cutting propagation

Issue [#1839](https://github.com/soulsimulation/souls/issues/1839). `core-cutting-donor@1` declares
`object:<donor-id>:take-cutting` with the exact empty nursery-pot ID in `text`. `core-nursery-pot@1` declares
`object:<pot-id>:plant-cutting` without parameters. Find the named objects and send their literal served IDs.

Three supplied visible donor shoots are finite. A completed native transfer removes one and puts the cutting in the
same empty pot, with a historical origin snapshot. Completed planting spends the pot's one soil and water portion
and retains the planted shoot. No free refill, reset or regrowth is supplied. The cutting/plant is integral to this
same pot; it is not a separate newborn entity, instant mature growth or proof of biological rooting time.

Empty hands, permission, exact definitions/state, native body/floor/reach and fixed table beside the donor are
required. Source/pot/support/parent ownership and started receipt bind atomic completion; interruption or stale work
produces nothing. Existing operate and nod/base-idle/release cleanup are approximate; no new rig or loose cutting
prop. Shared `commitSoulWork` preserves unrelated God Undo/redo.

Catalog/find/live expose both acts, text schema, finite shoots, stage, soil/water and planted count. Explicit current
inspection includes full origin/participant snapshots. Same-pot handling and state persistence preserve the result.
Only active receipts are sampled; no idle object scan. Proof measures absent, distant, nearby and in-use context.
