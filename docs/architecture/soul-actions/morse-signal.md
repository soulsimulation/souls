# Camp Morse signal lamp

Issue [#1831](https://github.com/soulsimulation/souls/issues/1831). `core-morse-signal-lamp@1` declares
`object:<lamp-id>:transmit`, with `text` of one to three letters A–Z or digits0–9 (case normalized). Discover the named
lamp and act ID through normal catalog/find, then send the literal ID and parameter. No word resolver is needed.

The same actual lamp must rest on a fixed table, with empty hands and permission. Its native plan walks there,
then alternates operation poses for dots0.5s/dashes1.5s and native gap poses. Only actual bound native operation
phases flash `on`. The first signaling phase spends one of three finite charges; approach spends nothing.
Interruption turns the signal off, keeps any spent charge spent, and preserves earlier completed history. No free
recharge/reset is supplied. Completed receipt records message, code, count and transmitter snapshot.

Kind defaults/live publish charges/on/active/pulse/count. Explicit current inspection gives full selected/completed
message and Morse code with requirements and historical attribution. No live foreign profile is queried. Same-item
native carry/placement and entity-state persistence retain the lamp and history. Only active sessions are sampled;
proof measures absent, distant, near and in-use here-frame sizes. A once-only startup recovery clears a persisted
interrupted session without restoring its spent charge or changing completed history; there is no idle recovery scan.

Permission, owner/access, definition, relevant state, transforms, support, body, native program and started receipt
bind each phase and completion. Shared `commitSoulWork` keeps pulse/history out of God Undo. No renderer moves the
actor or invents a timer. The existing emissive-face glow renders state; there is no surrounding illumination claim. Operation and grip are approximate, with release/idle
cleanup. No receiver, long-distance optical readability, multi-Soul receipt, confidentiality or authenticity claim.

[PR #1835](https://github.com/soulsimulation/souls/pull/1835) hosts focused checks, native2×2 comparison and
[whole actual proof](https://github.com/soulsimulation/souls/releases/download/proofs-1835/pr-1835.signal-performance.mp4). Explicit
dependency base is recorded there; Claude alone owns T3 sign-off, CI allocation, integration and release.
