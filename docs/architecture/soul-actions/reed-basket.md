# Reed basket making

`core/reed-basket-frame@1` is a fixed ground-level waist-height workstand. Eight supplied integral reed portions become eight retained basket courses. Each four-second `object:<id>:weave` accepts string `amount` (`1`, `2`, `4`, default `1`) and string `color` (`natural`, `rust`, default `natural`). Course order and the last maker are durable kind state.

After all eight courses, the two-second `object:<id>:finish` enables actual native storage for one small existing item, at most 0.18 × 0.23 × 0.18 m and 1 kg. Native `put-in:<basket-id>` and `pick-up:<stored-item-id>` preserve real contents and custody. Unfinished storage refuses with an instruction to weave all eight courses. Find the named workstand, copy its declared act ID, and send it; no plain-word resolver rule or client edit.

Work needs empty hands, access, ordinary reachable ground and completed authoritative receipts. Interrupted, stale, moved, private or malformed work receives no credit. God Undo/Redo leaves finished Soul work intact through the shared completion adapter. Natural/rust courses are coarse integral bands, not independent physical reeds or precise finger weaving. The workstand is fixed; no loaded-parent carrying, changing mass, loose outputs or new collision/support contract is claimed.
