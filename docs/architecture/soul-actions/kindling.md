# Kindling preparation

Issue #1614; PR #1621. `core-kindling-block@1` has one finite wood stock, a declared parameter-free `prepare-kindling` act, an output surface and a worker position. Discover the actual block and its state through the catalog/live picture, then send `object:<actual-block-id>:prepare-kindling`.

Ordinary native walking and twenty seconds of existing craft work precede atomic stock consumption and one separate `core-kindling-bundle@1` placed on the block. Interruption creates nothing. Empty hands, access, clear standing room and an empty output are required; completion rechecks stock, target, permission, floor and actual reach. The same bundle supports ordinary pickup and placement. Its creation is engine-authored and survives God Undo; unrelated God edits remain undoable and redoable.

The generic tool gesture does not prove axe contact, arbitrary log input, restocking, ignition or fuel simulation. Original visual and matched-run proof retains its original source; the current integration delta uses the shared completion adapter and family/supplement discovery. See the PR journal for current native and cold-ID qualification.
