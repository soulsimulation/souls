# Sgraffito tile

`core/sgraffito-tile@1` is one portable ceramic tile with three abstract coating portions. Choose red, blue or gold, then four seconds of existing native brush-proxy work coats it. Choose a rectangular window using text `x1,z1 x2,z2` inside ±0.27m/±0.17m; completed scratch work subtracts that window from the contrasting coat. Six current windows can overlap; already exposed material cannot be scratched again. Recoating consumes another portion and resets all cuts; removed coating is discarded, never recovered. The same tile carries current composition and maker.

Work needs empty hands, actual resting-on fixed surface support, permission and unchanged started/completed identity/state/definition/authority/poses. Native duration and matching body/receipt are guarded. Soul completion uses the shared completion adapter, outside ordinary God Undo. The exact-definition renderer observes the remaining committed coating rectangles and owns no collision/movement path. No clay firing, separate tool custody, physical coating thickness or knife precision is claimed.
