# Conserved bell damper

Issue #1896 adds immutable `core-bell@4`; old revisions retain their bytes. Find the named bell, then send its
literal `object:<id>:fit-damper`, `object:<id>:remove-damper` or `object:<id>:ring`. No parameters or new words.
The declared covered/stored state always conserves one integral felt damper. Empty hands, ordinary same-floor
reach, original identity/owner/access/body/state and completed native work are required for fitting/removal.
The fixed-dimension new revision bounds the felt layout and standing reach; construction scaffolding is excluded.

Fitting/removal transfer the one felt damper only after three native seconds and a completed exact receipt.
Interrupted, stale, duplicate or refused work gives no credit. Shared `commitSoulWork` preserves work through God
Undo/redo. Full inspect exposes the current state/ring count and historical participant through a narrow own-family
reader overlay; other contact facts stay unchanged. Catalog/live publish declared scalar fields.

A covered bell refuses a NEW rope pull usefully; rings and the one-shot sound trigger do not change. Removing the
damper restores the same native bell pull and existing audio. This does not silence an already-playing tail,
simulate felt acoustics or add scores, audio nodes, new rigging, loose felt custody or a general mute framework.
No new world idle scan is added. Basic coarse work is acceptable; required actual evidence remains separate.
