# Chair-rise practice

`core-chair-rise@1` reuses the existing real single-seat chair geometry and native sit/stand. Discover its readable room/name in catalog/find, then send `object:<chair-id>:practice-rises` with text `3` or `5`. The kind declares parameters and completedSets/completedRepetitions/lastRepetitions state; full current facts include historical participant.

Native seat admission owns route, occupancy and transitions. Active sessions observe distinct seated-to-stand-up phases on the same chair/body. Only the final completed exact receipt, with all requested phases, final unoccupied standing state and unchanged permission/source/support, records a set. Interrupted sets earn no completed repetitions. Completion uses commitSoulWork and survives unrelated God Undo/redo.

Empty hands and an empty chair on its world floor are required. No chair movement, exercise health/strength, per-subtick observation, new animation, seat framework or multi-Soul exercise claim. No idle world scan. Source and proof belong to issue #1861 and its PR; Claude alone owns T3/CI/integration/merge/release.
