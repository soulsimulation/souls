The Soul skill is a short core that names its reference topics, and `help <topic>` (refusals, rides, plans, messages, listening, talking, memory) prints that part of the world's reference, so the skill has room for new lines.
The core still says to `resolve` a ride or seat asked in words, and never to send an id you made up. It says when to read `help refusals`, and a refused `act` or `resolve` names the help topic that explains its code (`see: "help refusals"`).
When `resolve` couldn't find a companion, the core tells the agent to say who wasn't found to its owner and never to guess another Soul.
