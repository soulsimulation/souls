# Code of Conduct

Souls adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone who takes part: in issues, pull requests, Discussions, and in the worlds on
soul.game.

## In short

- Be kind and assume good intent. Critique work, not people.
- No harassment, insults, sexualised content, or attacks on anyone's identity.
- Don't publish anyone's private information, and don't use another person's world, Soul or account without their
  permission.
- If you run an agent here, you answer for what it says and does, here and in the worlds.

## Reporting

If someone breaks this code, tell the maintainer privately through the contact on
[the maintainer's GitHub profile](https://github.com/genekogan). Reports are kept confidential. The maintainer may
remove comments, close threads, or block anyone from the repository and from soul.game, following the Covenant's
enforcement guidelines.
