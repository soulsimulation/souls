# Final-draw carry contact

`oracle.mjs` passively observes the production world renderer. Install `contactTools` with the actual people-kit URL, verified Soul/body/load bindings, served kind entry and source identity. Activate before lift and retain the whole native phase interval through release. The wrapper preserves render arguments, return value, poses and timing.

Each actual on-screen draw reads current wrist palms and the visible load matrix. Instanced roots are recovered from every submitted part, its geometry-local offset and mesh parent; hidden, missing or disagreeing parts fail. Both palms must be within 3 cm of the native load-local contact pair. Membership comes independently from native field 4, contacts from field 6, sampled on the actual depicted body clock. Missing, duplicate, stale or incomplete observations fail.

The pair is ordered carry-back to carry-front, **not** anatomical left/right. The page chooses its bijection at the recorded assignment boundary from body facing, using native order for an initial geometric tie. That is a drawing choice, not a native hand label. The observer locks the observed assignment for its uninterrupted native episode; turns or another member leaving cannot reset it. A real release, removal or changed assignment starts a new episode. Per-frame best matching cannot hide a hand swap.

A separate clock check reconstructs the expected load transform from raw native frame records, full Q30 motion brackets and slot translations. It compares actual corners/endpoints, including stationary-root pivots, against a one-frame native travel budget. Palms and load lagging together therefore cannot pass just because they remain close to each other.

Active carry, set-in, return and held phases are contact-graded. Native released and inactive intervals are retained separately, never counted as active passes or used as a grace period. Release continuity/completion needs its own observed evidence. The collector retains bounded raw witnesses and first failures while aggregate counts/maxima continue; this numeric oracle does not certify collisions, balance or natural elbows. Those require inspection of the original motion.

Run fixtures with `node --test tools/playtest/carry-contact/oracle.test.mjs`. Fixture success is not served proof. Historical entry-centre distances and pre-contract results remain diagnostics only.

`local.mjs` uses ordinary served clients and isolated local worlds. Its output stays ignored; explicit build/source bindings, actual entity/entry identities, ordinary camera input and confirmed cleanup are prerequisites. Use Playwright's own Chromium with a fresh profile. Never substitute an installed personal browser or a fixed-shot camera for manual desktop/touch evidence.
